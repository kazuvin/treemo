# キー操作

キーの割り当てと、キー操作を利用者に伝える手がかり（シグニファイア）。
要件は [要件定義](requirements.md) の EDIT・TREE・UX にある。

ここにあるのは MVP の仮決めで、使いながら見直す。割り当てを変えたら、この文書と
コマンドの登録を同じコミットで直す。

## 表記

| 表記 | 意味 |
| --- | --- |
| `⌘` / `⇧` / `⌥` | Command / Shift / Option |
| `<C-x>` | Control + x |
| `<Space>` | リーダーキー（エディタとサイドバーの NORMAL モードで有効） |
| `dd` | 続けて押す |

## コマンドとキーの範囲

キーはすべてコマンドの登録（`src/lib/command.ts` の `keys`）に書く。どのキーも、次の
範囲のどれか 1 つに属し、その範囲が有効なときだけ効く。当たらなかったキーは Vim に届く。

| 範囲 | 有効なとき |
| --- | --- |
| `global` | いつでも（パレットやダイアログを開いている間も）。`⌘` の組み合わせだけを置く |
| `normal` | サイドバーにフォーカスがあるとき、またはエディタが NORMAL で Vim がキーの続きを待っていないとき |
| `editor` | エディタが NORMAL か INSERT のとき（`<M-…>` のリスト操作） |
| `sidebar` | サイドバーにフォーカスがあるとき |
| `block` | エディタが NORMAL で、カーソルがツリーブロックに乗っているとき |
| `tree` | TREE モードで、ノードを編集していないとき |

- 入力欄（パレット、スイッチャー、名前の入力、`:` のコマンド行）にフォーカスがあるときは
  `global` だけが効く。ノードを編集している間も `global` だけ。
- TREE モードでは、どのコマンドにも当たらない文字のキーを飲み込む（隠れているブロックの
  テキストを Vim が書き換えないように）。ブロックの上でも、検索や取り消しなど害の無いキー
  （`:` `/` `?` `n` `N` `u` `<C-r>` `G` `z` など）以外は飲み込む。
- ブロックの上の `g` のように、続けて押すキーの途中でどのコマンドにも当たらなくなったら、
  押したキーをそのまま Vim に渡し直す（`gg` は Vim の `gg` として効く）。`<Space>` と `<C-w>`
  で始まるものは渡し直さない。

## モード

| モード | 入り方 | 出方 | 表示 |
| --- | --- | --- | --- |
| NORMAL | 既定 | — | ステータスバーに `NORMAL` |
| INSERT / VISUAL | Vim と同じ | `Esc` | ステータスバーに `INSERT` / `VISUAL` |
| TREE | ブロックの上で `Enter` | `Esc` / `q` | ステータスバーに `TREE`。操作中のブロックの枠をアクセント色にする |
| ノード編集 | TREE で `i` / `a` / `c` / `o` など | NORMAL で `Esc` | ステータスバーに `TREE · INSERT` などと重ねて出す |

アクセント色は Kotoba で「フォーカスと選択状態」にだけ使える。TREE モードの枠は
「今キー入力を受け取っている場所」を示すフォーカスの一種として扱う。

## どこでも効くキー

macOS の慣習に合わせる。Vim のキーとぶつからないよう `⌘` を使う。

| キー | 動作 |
| --- | --- |
| `⌘K` | コマンドパレット |
| `⌘P` | クイックスイッチャー（ファイルを開く・作る） |
| `⌘N` | 新しいメモ |
| `⌘\` | サイドバーの表示を切り替える |
| `⌘/` | キー操作の一覧 |
| `⌘,` | 設定（下の「設定画面」） |

設定はパレットからも切り替えられる（サイドバーの左右、テーマ、TREE モードの次のキーの案内）。

## リーダーキー（which-key）

エディタやサイドバーの NORMAL モードで `<Space>` を押すと、続けて押せるキーの一覧を
画面の下に出す。一覧はコマンドの登録から作るので、ここと画面が食い違うことはない。

| キー | 動作 |
| --- | --- |
| `<Space><Space>` | コマンドパレット |
| `<Space>ff` | クイックスイッチャー |
| `<Space>fn` | 新しいメモ |
| `<Space>fr` | 名前を変える |
| `<Space>fm` | 移動する |
| `<Space>fd` | 削除する（ゴミ箱へ） |
| `<Space>tn` | ここに空のツリーブロックを差し込み、TREE モードに入る |
| `<Space>x` | カーソル行のチェックボックスを切り替える |
| `<Space>j` | ヒント（画面の押せる要素にラベルを出す） |
| `<Space>e` | サイドバーへフォーカスを移す |
| `<Space>?` | キー操作の一覧 |

## フォーカスの移動

サイドバーは設定で本文の左右どちらにも置ける。左右を向きで指すキーは、置いた側に合わせて
行き先が入れ替わる。

| キー | 動作 |
| --- | --- |
| `<C-w>h` / `<C-w>l` | 左 / 右の領域へ移る（サイドバーが左なら `h` でサイドバー、`l` で本文） |
| 本文の行頭で `h` | サイドバーが左にあれば、サイドバーへ移る |
| 本文の行末で `l` | サイドバーが右にあれば、サイドバーへ移る |
| サイドバーで `j` / `k` | 項目を移る |
| サイドバーで `l` | フォルダを開く。メモなら開いて本文へ移る |
| サイドバーで `Enter` | フォルダの開閉を切り替える。メモなら開いて本文へ移る |
| サイドバーで `h` | フォルダを閉じる、親へ移る。サイドバーが右で、どちらも無い一番上の項目なら本文へ移る |
| サイドバーで `gg` / `G` | 最初 / 最後の項目へ |
| サイドバーで `Esc` | 本文へ戻る |

- 行頭の `h` と行末の `l` は、Vim ではその先に動けない（何も起きない）キーなので、動けない
  ときだけサイドバーへの移動に使う。NORMAL で Vim がキーの続きを待っていないときだけ効く
  （`dh` の `h` は Vim のまま）。
- **押し続けたときの自動の繰り返しでは移らない。** `h` を押し続けて行頭まで戻ったときに、
  勢いでサイドバーへ飛ばないようにするため。移るには、行頭でもう一度押し直す。
- サイドバーを隠しているときは、端のキーは Vim のまま（サイドバーを出さない）。

フォーカスのある領域（サイドバーかエディタか）は、その領域の上端のアクセント色の線と、
ステータスバーの表示で示す。サイドバーにフォーカスがある間は、下端に次のキーの案内
（`j k 移動 · l 開く · Enter 開閉 · h 閉じる · Esc エディタへ`）を出す。

## エディタ（Vim に足すもの）

Vim の標準の操作はそのまま使える。足すのはアウトライナーの操作。

| キー | 動作 |
| --- | --- |
| `za` / `zo` / `zc` | 見出し・リスト項目を折りたたむ / 開く（Vim の fold と同じ） |
| `zR` / `zM` | すべて開く / すべて折りたたむ |
| `<M-l>` / `<M-h>` | リスト項目を子ごと字下げ / 字上げ |
| `<M-j>` / `<M-k>` | リスト項目を子ごと下 / 上へ入れ替える |
| `:w` | 保存（自動保存とは別に、今すぐ書く） |
| `:e 名前` | メモを開く |

`<M-…>` は Option キー。macOS では Option が文字の入力に使われるので、
CodeMirror 側で Option を修飾キーとして扱う設定が要る。

## ツリーブロックの上

カーソルがブロックに乗ると、ブロックが選択状態になり、次のキーを案内する。ブロックの
直前（直後）の行で `j`（`k`）を押すとブロックに乗る。Vim の `j` / `k` は絵の中に入れない
ので、この 2 つはコマンドとして受ける。

| キー | 動作 |
| --- | --- |
| `Enter` | TREE モードに入る（最後に使った表示: インラインか全画面か） |
| `gs` | ソース表示にする（生のテキストを Vim で編集する） |
| `j` / `k` | ブロックを飛び越えて前後の行へ移る |
| `o` / `O` | ブロックの下 / 上に行を足して書き始める |

ノードをクリックすると、そのノードを選んで TREE モードに入る。ダブルクリックで編集する。

## TREE モード

### 移動

左から右へ広がるツリーなので、`h` / `l` が親と子、`j` / `k` が兄弟になる。

| キー | 動作 |
| --- | --- |
| `h` | 親へ |
| `l` | 子へ（最後に居た子。初めてなら最初の子） |
| `j` / `k` | 下 / 上の兄弟へ |
| `gg` / `G` | 最初のルート / 最後に見えている葉へ |
| `f` | ヒント。見えているノードにラベルを出し、打ったノードへ飛ぶ |
| `zz` | 選んでいるノードを画面の中央に寄せる |

### 組み立て

| キー | 動作 |
| --- | --- |
| `o` / `O` | 下 / 上に兄弟ノードを足して、中身を書き始める |
| `Tab` | 子ノードを足して、中身を書き始める |
| `i` / `a` | 中身の先頭 / 末尾から書き始める |
| `c` | 中身を消して書き直す |
| `>` / `<` | 字下げ / 字上げ（部分木ごと） |
| `J` / `K` | 下 / 上の兄弟と入れ替える（部分木ごと） |
| `dd` | 部分木ごと削除（レジスタへ） |
| `yy` | 部分木ごとコピー |
| `p` / `P` | 下 / 上に兄弟として貼り付け |
| `]p` | 最後の子として貼り付け |
| `za` / `zR` / `zM` | 折りたたみの切り替え / すべて開く / すべて折りたたむ |
| `u` / `<C-r>` | 取り消し / やり直し（メモ全体の履歴と共通） |

### 表示と終了

| キー | 動作 |
| --- | --- |
| `F` | インラインと全画面を切り替える |
| `Esc` / `q` | TREE モードを出て、ブロックの直後にカーソルを置く |

## ノード編集

ノードの上に小さなエディタを開く。Vim が使え、複数行を書ける。

ロジックツリーは「書いて、次を足して、また書く」を速く回したいので、INSERT モードの
`Enter` と `Tab` はマインドマップの道具と同じ意味にしてある。

| モード | キー | 動作 |
| --- | --- | --- |
| INSERT | `Enter` | 確定し、下に兄弟ノードを足して書き続ける。中身が空なら、そのノードを消して TREE に戻る |
| INSERT | `Tab` | 確定し、子ノードを足して書き続ける |
| INSERT | `⇧Enter` | ノードの中で改行する |
| INSERT | `Esc` | ノード編集の NORMAL へ（Vim と同じ） |
| NORMAL | `Esc` | 確定して TREE に戻る。`o` などで足したばかりのノードが空なら消す |

## Vim のキーとぶつかるもの

- **`<Space>`**: Vim の NORMAL では「右へ 1 文字」だが、`l` と同じなのでリーダーに使う。
- **ヒント**: Vim の `f` は「行の中の文字へ飛ぶ」なので、エディタでは `<Space>j` にした。
  TREE モードには文字の移動が無いので `f` を使う。
- **`J` / `K`**: Vim では行の結合とキーワード検索。TREE モードの中だけ入れ替えに使う。

## 割り当てを変える

ここまでの表は既定の割り当て。変える方法は 2 つあり、どちらも Application Support
（`~/Library/Application Support/me.kazuvin.treemo/`）の `keybindings.json` に書かれる。

### 設定画面

`⌘,` の設定画面の「キー」（`Tab` で「一般」と切り替える）。すべてのコマンドを、割り当て
1 つにつき 1 行で並べる。

| キー | 動作 |
| --- | --- |
| `j` / `k`、`g` / `G` | 行を移る / 最初・最後の行へ |
| `Enter` / `c` | その割り当てを押し直す（キーの無いコマンドなら足す） |
| `a` | 割り当てを足す |
| `d` / `x` | その割り当てを外す |
| `s` | その割り当ての範囲を次のものに変える |
| `r` | そのコマンドを既定の割り当てに戻す |
| `/` | 名前・ID・キーで絞り込む（`Enter` で決める、`Esc` で消す） |
| `Esc` / `q` | 設定画面を閉じる |

- 押し直すときは、割り当てたいキーをそのまま押す。最後のキーから 1 秒で決まるので、
  `<Space>ff` のような続けて押すキーも押せる。最初に `Esc` を押すとやめる（`Esc` そのものは
  ここでは割り当てられないので、ファイルに書く）。記録している間は、どのコマンドもキーで
  走らない。
- 範囲は、`⌘` の組み合わせなら `global`、それ以外は元の割り当て（無ければ `normal`）に
  そろえる。違えば `s` で変える。
- 同じ範囲で同じキーを持つコマンドがあれば、その行の下に出す。
- 変えるとすぐに効き、既定と違うものだけを `keybindings.json` に書く。既定に戻した
  コマンドはファイルから消える。ファイルに手で書いた、アプリに無いコマンドの ID は残す。

### ファイルに書く

パレットの「キーの割り当てを変える」（`app.editKeybindings`）か、設定画面の「一般」の
「キーの割り当てのファイル」で、無ければ空の形で作り、既定のテキストエディタで開く。

```json
{
  "app.focusSidebar": [
    { "scope": "normal", "sequence": "<C-h>" },
    { "scope": "normal", "sequence": "<Space>e" }
  ],
  "app.focusEditor": [{ "scope": "sidebar", "sequence": "<C-l>" }],
  "vault.trash": []
}
```

- 鍵はコマンドの ID。ID は設定画面の「キー」と、キー操作の一覧（`⌘/`）に出る。
- 値はそのコマンドの割り当ての**すべて**。書いたものが既定を丸ごと置き換える（足したい
  ときは既定のものも書く）。空の配列はキーを外す。
- `scope` は「コマンドとキーの範囲」の表のどれか。`sequence` はこの文書の表記で書く。
- 保存してアプリのウィンドウに戻ると読み直す。パレットの「キーの割り当てを読み直す」でも
  読み直せる。
- 書き間違い（JSON として読めない、無い範囲、無いコマンドの ID）はステータスバーに出す。
  読めなかったときは、それまでの割り当てのまま動く。
- 変えた割り当ては、パレット・which-key・キー一覧・サイドバーの案内・空の画面の案内に
  そのまま出る。TREE モードの次のキーの案内（`KeyGuide`）はまだ既定のキーを書いたまま。
- Vim 側で割り当ててあるキー（`za`、`:w` など、一覧に出るだけのもの）は、置き換えても
  Vim の中では効き続ける。INSERT のノード編集の `Enter` / `Tab` も変えられない。

## 設定画面

`⌘,` で開く。`Tab` で「一般」と「キー」を切り替え、`Esc` / `q` で閉じる。「キー」は上の
「割り当てを変える」にある。「一般」は `j` / `k` で項目を移り、`h` / `l`（`Enter` / `Space`）で
値を変える。

| 項目 | 値 |
| --- | --- |
| サイドバーの位置 | 左 / 右 |
| テーマ | [Kotoba](kotoba-design-system.md) の「テーマ」にあるもの |
| TREE モードの次のキーの案内 | 出す / 出さない |
| 保管庫 | `Enter` で選び直す |
| キーの割り当てのファイル | `Enter` で `keybindings.json` を開く |

値は変えるとすぐに効き、アプリの状態として保存する。

## 手がかり（シグニファイア）

キーボードで使う道具は、押せるキーが目に見えないと覚えられない。次の手がかりを常に
出し、マウスで操作した人も次からキーを使えるようにする。

| 手がかり | 出す場所 | 中身 |
| --- | --- | --- |
| モード表示 | ステータスバー | 今のモード。TREE では操作中のブロックの枠も変える |
| which-key | 画面の下 | `<Space>` のあとに押せるキーと、その動作 |
| ヒント | 押せる要素の上 | 1〜2 文字のラベル。打つとそこへ移る |
| 次のキーの案内 | 選んでいるブロックの下端、全画面では上端 | `o 兄弟` `Tab 子` `i 編集` のように主なものだけ。ノード編集中は Enter / Tab の意味。パレットの「次のキーの案内を切り替える」で消せる |
| コマンドパレット | `⌘K` | すべてのコマンドと割り当てキー。打った名前で絞り込む |
| ツールチップ | マウスで押せる要素 | その操作の割り当てキー（ボタン、チェックボックス、折りたたみの数） |
| フォーカスリング | フォーカスのある領域 | サイドバー・エディタ・パレットのどこにキー入力が行くか |
