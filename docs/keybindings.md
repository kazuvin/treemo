# キー操作

キーの割り当てと、キー操作を利用者に伝える手がかり（シグニファイア）。
要件は [要件定義](requirements.md) の EDIT・TREE・UX にある。

ここにあるのは MVP の仮決めで、使いながら見直す。割り当てを変えたら、この文書と
コマンドの登録を同じコミットで直す。

## 表記

| 表記 | 意味 |
| --- | --- |
| `⌘` / `⇧` / `⌥` | Command / Shift / Option |
| `<C-x>` | Control + x |
| `<Space>` | リーダーキー（エディタとサイドバーの NORMAL モードで有効） |
| `dd` | 続けて押す |

## コマンドとキーの範囲

キーはすべてコマンドの登録（`src/lib/command.ts` の `keys`）に書く。どのキーも、次の
範囲のどれか 1 つに属し、その範囲が有効なときだけ効く。当たらなかったキーは Vim に届く。

| 範囲 | 有効なとき |
| --- | --- |
| `global` | いつでも（パレットやダイアログを開いている間も）。`⌘` の組み合わせだけを置く |
| `normal` | サイドバーにフォーカスがあるとき、またはエディタが NORMAL で Vim がキーの続きを待っていないとき |
| `editor` | エディタが NORMAL か INSERT のとき（`<M-…>` のリスト操作） |
| `sidebar` | サイドバーにフォーカスがあるとき |
| `block` | エディタが NORMAL で、カーソルがツリーブロックに乗っているとき |
| `diagram` | DIAGRAM (NORMAL) のとき（ノードを編集していないとき） |

- 入力欄（パレット、スイッチャー、名前の入力、`:` のコマンド行）にフォーカスがあるときは
  `global` だけが効く。ノードを編集している間（DIAGRAM (INSERT)）も `global` だけ。
- DIAGRAM モードでは、どのコマンドにも当たらない文字のキーを飲み込む（隠れているブロックの
  テキストを Vim が書き換えないように）。ブロックの上でも、検索や取り消しなど害の無いキー
  （`:` `/` `?` `n` `N` `u` `<C-r>` `G` `z` など）以外は飲み込む。
- ブロックの上の `g` のように、続けて押すキーの途中でどのコマンドにも当たらなくなったら、
  押したキーをそのまま Vim に渡し直す（`gg` は Vim の `gg` として効く）。`<Space>` と `<C-w>`
  で始まるものは渡し直さない。

## モード

| モード | 入り方 | 出方 | 表示 |
| --- | --- | --- | --- |
| NORMAL | 既定 | — | ステータスバーに `NORMAL` |
| INSERT / VISUAL | Vim と同じ（VISUAL は `v` / `V` / `<C-v>`） | `Esc` | ステータスバーに `INSERT` / `VISUAL` |
| DIAGRAM (NORMAL) | ブロックの上で `Enter` | `Esc` / `q` | ステータスバーに `DIAGRAM (NORMAL)`。操作中のブロックの枠をアクセント色にし、選んでいるノード（カーソル）を本文の Vim のカーソルと同じ色の枠とティントで示す。ノードの枠は本文の Vim のカーソルと同じ周期（1.2 秒）で点滅する |
| DIAGRAM (INSERT) | DIAGRAM (NORMAL) で `i` / `a` / `c` / `o` など | `Esc`（確定して DIAGRAM (NORMAL) へ） | ステータスバーに `DIAGRAM (INSERT)`。編集中のノードに文字のカーソルを出す |

アクセント色は Kotoba で「フォーカスと選択状態」にだけ使える。DIAGRAM モードの枠は
「今キー入力を受け取っている場所」を示すフォーカスの一種として扱う。

ツリーブロックの枠は、カーソルがブロックに乗っているとき（本文の Vim のカーソルと同じ色の線）と DIAGRAM モードの
とき（アクセント色）にだけ出す。それ以外（外にいるとき、全画面で編集しているあいだのインラインの
ブロック）は枠を透明にして、図が本文に溶け込むようにする。枠の場所は常に取っておくので、
枠が出入りしても本文は動かない。

カーソルがブロックに乗っているときの枠は、本文のカーソルの代わりなので、Vim のカーソルと同じ
周期（1.2 秒）で点滅させる。DIAGRAM (NORMAL) で選んでいるノードの枠も同じく点滅する。DIAGRAM
モードのブロックの枠と、DIAGRAM (INSERT) で編集中のノードの枠は点滅させない（INSERT では
文字のカーソルが点滅する）。エディタからフォーカスが外れているときと、OS で視差効果を減らす設定の
ときは点滅しない。

## 閲覧モード

Obsidian の閲覧ビューにあたる。本文の右上のスイッチ（鉛筆が編集、本が閲覧）か `⌘E`
（パレットの「編集モードと閲覧モードを切り替える」）で切り替える。どのメモでも同じ表示で開き、
アプリの状態として覚えておく。スイッチは選んでいる側の塗りが滑って移り、切り替えるたびに
スイッチの下の左右中央へ「閲覧モード」「編集モード」と 1.6 秒だけ出す
（キーやパレットで切り替えたときも出す）。

- どの行も装飾した形で見せる（カーソルの行も生の Markdown に戻さない）。フロントマターと
  本文の表は表のまま、ツリーブロックは絵のまま（ソース表示にしていたブロックも絵に戻す）。
- 本文は書き換えられない。Vim の移動（`j` / `k`、`<C-d>`、`gg`、検索など）はそのまま使え、
  スクロールに使う。カーソルは出さない。`i` などで INSERT に入ろうとしても NORMAL に戻す。
- チェックボックスは押して切り替えられる（Obsidian と同じ）。外で書き換わったファイルの
  読み込みも通す。
- ブロックには乗らず、DIAGRAM モードにも入れない（ノードを押しても入らない）。
  DIAGRAM モードの途中で閲覧モードにすると、DIAGRAM モードを出てから切り替える。

## どこでも効くキー

macOS の慣習に合わせる。Vim のキーとぶつからないよう `⌘` を使う。

| キー | 動作 |
| --- | --- |
| `⌘K` | コマンドパレット |
| `⌘P` | クイックスイッチャー（ファイルを開く・作る） |
| `⌘N` | 新しいメモ |
| `⌘\` | サイドバーの表示を切り替える |
| `⌘0` / `⌘1` | サイドバー / 本文へ移る（INSERT の途中でも効く） |
| `⌘/` | キー操作の一覧 |
| `⌘E` | 編集モードと閲覧モードを切り替える（上の「閲覧モード」） |
| `⌘,` | 設定（下の「設定画面」）。サイドバー右上の歯車からも開ける |
| `⌘=`（`⌘+`）/ `⌘-` | 文字を大きく / 小さくする（設定の「文字の大きさ」を 1 段ずつ）。既定に戻すのはパレットから |

設定はパレットからも切り替えられる（サイドバーの左右、文字の大きさ、テーマ、書体、BGM とその音量、DIAGRAM モードの次のキーの案内）。

## リーダーキー（which-key）

エディタやサイドバーの NORMAL モードで `<Space>` を押すと、続けて押せるキーの一覧を
画面の下に出す。一覧はコマンドの登録から作るので、ここと画面が食い違うことはない。

| キー | 動作 |
| --- | --- |
| `<Space><Space>` | コマンドパレット |
| `<Space>ff` | クイックスイッチャー |
| `<Space>fn` | 新しいメモ |
| `<Space>fr` | 名前を変える |
| `<Space>fm` | 移動する |
| `<Space>fd` | 削除する（ゴミ箱へ） |
| `<Space>ft` | タグで探す（下の「タグ検索」） |
| `<Space>tn` | ここに空のツリーブロックを差し込み、DIAGRAM モードに入る |
| `<Space>x` | カーソル行のチェックボックスを切り替える |
| `<Space>j` | ヒント（画面の押せる要素にラベルを出す） |
| `<Space>e` | サイドバーの表示を切り替える（`⌘\` と同じ。サイドバーの中でも効く） |
| `<Space>m` | BGM を流す / 止める（止める前に流していたものに戻す。初めは「テーマに合わせる」） |
| `<Space>?` | キー操作の一覧 |

## フォーカスの移動

サイドバーは設定で本文の左右どちらにも置ける。左右を向きで指すキーは、置いた側に合わせて
行き先が入れ替わる。

カーソルの位置に関わらず移れるキーは次の 3 つ。本文の端のキーは、その補い。

| キー | 動作 |
| --- | --- |
| `⌘0` / `⌘1` | サイドバー / 本文へ移る。どのモードでも効く（VS Code と同じキー） |
| `<C-w>w` / `<C-w><C-w>` | サイドバーと本文を行き来する（Vim の「次のウィンドウへ」と同じ） |
| `<C-w>h` / `<C-w>l` | 左 / 右の領域へ移る（サイドバーが左なら `h` でサイドバー、`l` で本文） |
| 本文の行頭で `h` | サイドバーが左にあれば、サイドバーへ移る |
| 本文の行末で `l` | サイドバーが右にあれば、サイドバーへ移る |
| サイドバーで `j` / `k` | 項目を移る |
| サイドバーで `l` | フォルダを開く。メモなら開いて本文へ移る |
| サイドバーで `Enter` | フォルダの開閉を切り替える。メモなら開いて本文へ移る |
| サイドバーで `h` | フォルダを閉じる、親へ移る。サイドバーが右で、どちらも無い一番上の項目なら本文へ移る |
| サイドバーで `gg` / `G` | 最初 / 最後の項目へ |
| サイドバーで `Esc` | 本文へ戻る |

- 行頭の `h` と行末の `l` は、Vim ではその先に動けない（何も起きない）キーなので、動けない
  ときだけサイドバーへの移動に使う。NORMAL で Vim がキーの続きを待っていないときだけ効く
  （`dh` の `h` は Vim のまま）。
- **押し続けたときの自動の繰り返しでは移らない。** `h` を押し続けて行頭まで戻ったときに、
  勢いでサイドバーへ飛ばないようにするため。移るには、行頭でもう一度押し直す。
- サイドバーを隠しているときは、端のキーは Vim のまま（サイドバーを出さない）。

フォーカスのある領域（サイドバーかエディタか）は、その領域の上端のアクセント色の線と、
ステータスバーの表示で示す。サイドバーにフォーカスがある間は、下端に次のキーの案内
（`j k 移動 · l 開く · Enter 開閉 · h 閉じる · Esc エディタへ`）を出す。
本文にフォーカスが無い間（サイドバー・パレット・別のアプリにいる間）は、本文のカーソルを隠す。

## エディタ（Vim に足すもの）

Vim の標準の操作（`<C-d>` / `<C-u>` の半画面の移動、`v` / `V` / `<C-v>` の VISUAL など）は
そのまま使える。足すのはアウトライナーの操作と、Markdown を書くときに欲しいもの。

Vim は CodeMirror の標準のキー割り当てより前に置く。macOS では標準の割り当てに Emacs 風の
`Ctrl-d`（1 文字削除）`Ctrl-v` `Ctrl-o` などがあり、後ろに置くとそちらが先に効いてしまう。

| キー | 動作 |
| --- | --- |
| `]]` / `[[` | 次 / 前の見出しへ（コードブロックの中の `#` は数えない） |
| `Y` | カーソルから行末までコピー（Neovim の既定と同じ。設定で外せる） |
| `:wq` / `:x` | 保存（ウィンドウは閉じない。手癖で打っても困らないように） |
| `za` / `zo` / `zc` | 見出し・リスト項目を折りたたむ / 開く（Vim の fold と同じ） |
| `zR` / `zM` | すべて開く / すべて折りたたむ |
| `<M-l>` / `<M-h>` | リスト項目を子ごと字下げ / 字上げ |
| `<M-j>` / `<M-k>` | リスト項目を子ごと下 / 上へ入れ替える |
| `:w` | 保存（自動保存とは別に、今すぐ書く） |
| `:e 名前` | メモを開く |

`<M-…>` は Option キー。macOS では Option が文字の入力に使われるので、
CodeMirror 側で Option を修飾キーとして扱う設定が要る。

## 検索

Vim の `/` `?` `n` `N` `*` `#` をそのまま使う。ツリーブロックの中の行に当たると、そのノードを
選んで DIAGRAM (NORMAL) に入る（[ツリーブロック](tree-block.md) の「検索」）。

当たりの光り（hlsearch）は、検索が済んだら消す。`n` `N` `*` `#` `/` `?` 以外のキーを押した
ところで消えるので、`n` で当たりを渡り歩いている間だけ光る。`:noh` でも消せる。

## ツリーブロックの上

カーソルがブロックに乗ると、ブロックが選択状態になり、次のキーを案内する。ブロックの
直前（直後）の行で `j`（`k`）を押すとブロックに乗る。Vim の `j` / `k` は絵の中に入れない
ので、この 2 つはコマンドとして受ける。

| キー | 動作 |
| --- | --- |
| `Enter` | DIAGRAM モードに入る（最後に使った表示: インラインか全画面か） |
| `gs` | ソース表示にする（生のテキストを Vim で編集する） |
| `j` / `k` | ブロックを飛び越えて前後の行へ移る |
| `o` / `O` | ブロックの下 / 上に行を足して書き始める |

ノードをクリックすると、そのノードを選んで DIAGRAM モードに入る。ダブルクリックで編集する。

## DIAGRAM モード

### 移動

左から右へ広がるツリーなので、`h` / `l` が親と子、`j` / `k` が兄弟になる。

| キー | 動作 |
| --- | --- |
| `h` | 親へ |
| `l` | 子へ（最後に居た子。初めてなら最初の子） |
| `j` / `k` | 同じ深さの下 / 上のノードへ。兄弟が尽きたら親を跨いで、いとこへ移る |
| `gg` / `G` | 最初のルート / 最後に見えている葉へ |
| `f` | ヒント。見えているノードにラベルを出し、打ったノードへ飛ぶ |
| `zz` | 選んでいるノードを画面の中央に寄せる |

### 組み立て

| キー | 動作 |
| --- | --- |
| `o` / `O` | 下 / 上に兄弟ノードを足して、中身を書き始める |
| `Tab` | 子ノードを足して、中身を書き始める |
| `i` / `a` | 中身の先頭 / 末尾から書き始める |
| `c` | 中身を消して書き直す |
| `>` / `<` | 字下げ / 字上げ（部分木ごと） |
| `J` / `K` | 下 / 上の兄弟と入れ替える（部分木ごと） |
| `dd` | 部分木ごと削除（レジスタへ） |
| `yy` | 部分木ごとコピー |
| `p` / `P` | 下 / 上に兄弟として貼り付け |
| `]p` | 最後の子として貼り付け |
| `za` / `zR` / `zM` | 折りたたみの切り替え / すべて開く / すべて折りたたむ |
| `u` / `<C-r>` | 取り消し / やり直し（メモ全体の履歴と共通） |

### 表示と終了

| キー | 動作 |
| --- | --- |
| `+` / `-` / `0` | 図を拡大 / 縮小 / 100% に戻す。倍率は 50〜200% の 9 段で、インラインと全画面で共通 |
| `=` | 図を画面の大きさに合わせる。インラインでは本文の幅に、全画面では画面の幅と高さに収まるよう縮め（大きくはしない。下限 25%）、ウィンドウの大きさやノードが変わるたびに合わせ直す。`+` / `-` を押すと合わせるのをやめ、そのときの倍率から 1 段動かす（`0` なら 100% に戻す） |
| `F` | インラインと全画面を切り替える |
| `Esc` / `q` | DIAGRAM モードを出て、ブロックの直後にカーソルを置く |
| `n` / `N` | 選んでいるノードの後ろ（前）から、本文の検索を続ける（[ツリーブロック](tree-block.md) の「検索」） |

倍率は案内の行の右端の `−` `100%` `+` `合わせる` のボタンでも変えられ、パレットからは DIAGRAM モードの
外でも変えられる。合わせているあいだは `合わせる` を選択の見た目にする。

## ノード編集（DIAGRAM (INSERT)）

ノードの上に小さなエディタを開く。複数行を書ける。`Esc` 1 回で DIAGRAM (NORMAL) に
戻れるよう、このエディタの中では Vim を使わない（NORMAL にあたるのは DIAGRAM (NORMAL)）。

ロジックツリーは「書いて、次を足して、また書く」を速く回したいので、`Enter` と `Tab` は
マインドマップの道具と同じ意味にしてある。

| キー | 動作 |
| --- | --- |
| `Enter` | 確定し、下に兄弟ノードを足して書き続ける。中身が空なら DIAGRAM (NORMAL) に戻る（下の「空のノード」） |
| `Tab` | 確定し、子ノードを足して書き続ける。中身が空なら何もしない |
| `⇧Enter` | ノードの中で改行する |
| `Esc` | 確定して DIAGRAM (NORMAL) に戻る（DIAGRAM モードは出ない）。中身が空なら下の「空のノード」のとおり |
| `⌘Z` / `⇧⌘Z` | ノードの中の取り消し / やり直し |

空のノード: 空白だけの中身は空とみなし、アプリの操作では空のノードを作らない。
空で確定したノードは、子が無ければ消す。子があれば、部分木ごと消えないよう編集前の
中身に戻す。ファイルに書かれた `-` だけの行は、そのまま空のノードとして読む。

## Vim の設定

Vim の割り当ては、利用者があとから設定で変えられる前提で持つ。設定画面はまだ無い。

- 形は `src/features/editor/utils/vim-config.ts` の `VimConfig`。アプリの状態
  （`state.json` の `vim`）に保存し、起動時に `applyVimConfig` で Vim に流す。設定画面は
  値を書き換えて `applyVimConfig` を呼び直せばよい。
- `mappings` は Vim の `:noremap` / `:map` と同じ意味の一覧（モード・押すキー・置き換えるキー）。
  `applyVimConfig` は `:mapclear` してから入れ直すので、一覧から消した割り当ては残らない。
- 入れる順番は「Vim の標準 → Treemo が足すキー（`za` `]]` など）→ `mappings`」。
  あとに入れたものが勝つので、利用者の割り当てがいちばん強い。
- `Y` のような Treemo の好みで足した割り当ては、`mappings` の既定値に置く。一覧を
  置き換えれば外せる。
- `clipboard` は Vim の `clipboard=unnamed` にあたる。`unnamed`（既定）なら、`y` と DIAGRAM
  モードの `yy` でコピーした中身を macOS のクリップボードにも書く。削除（`x` / `dd`）は
  書かない。消すたびにクリップボードが上書きされると、ほかのアプリへ貼りにくいため。
  ほかのアプリでコピーしたものは `⌘V` か `"+p` で貼る。
- Treemo のコマンドのキー（`<Space>` のリーダー、DIAGRAM モードなど）は Vim の割り当てとは
  別に、コマンドの登録（`src/lib/command.ts` の `keys`）にある。こちらを変えられるように
  するときは、コマンドの ID → キーの上書きを同じくアプリの状態に置く。

## フロントマター

フロントマターの表は、カーソルが入ると YAML のテキストに戻る。表のためのキーは無く、
Vim の移動（`gg`、表の次の行での `k`）で入る。表を押しても入る。

## 表

本文の表（F-EDIT-8）も、カーソルが入ると生の Markdown に戻る。表のためのキーは無く、
Vim の移動（表の前後の行での `j` / `k`）で入る。表を押しても入る。横に収まらない表は、

## タグ検索

`<Space>ft`（パレットの「タグで探す」）で開く。フロントマターのタグのチップを押す（`<Space>j` の
ヒントでも押せる）と、そのタグのメモの一覧から始まる。

| キー | 動作 |
| --- | --- |
| 文字 | タグ / メモの名前で絞り込む |
| `↑` / `↓`、`Enter` | 選ぶ。タグならそのメモの一覧へ、メモなら開く |
| `⌫`（何も打っていないとき） | メモの一覧からタグの一覧へ戻る |
| `Esc` | 閉じる |

## Vim のキーとぶつかるもの

- **`<Space>`**: Vim の NORMAL では「右へ 1 文字」だが、`l` と同じなのでリーダーに使う。
- **ヒント**: Vim の `f` は「行の中の文字へ飛ぶ」なので、エディタでは `<Space>j` にした。
  DIAGRAM モードには文字の移動が無いので `f` を使う。
- **`J` / `K`**: Vim では行の結合とキーワード検索。DIAGRAM モードの中だけ入れ替えに使う。

## 割り当てを変える

ここまでの表は既定の割り当て。変える方法は 2 つあり、どちらも Application Support
（`~/Library/Application Support/me.kazuvin.treemo/`）の `keybindings.json` に書かれる。

### 設定画面

`⌘,` の設定画面の「キー」（`Tab` で「一般」と切り替える）。すべてのコマンドを、割り当て
1 つにつき 1 行で並べる。

| キー | 動作 |
| --- | --- |
| `j` / `k`、`g` / `G` | 行を移る / 最初・最後の行へ |
| `Enter` / `c` | その割り当てを押し直す（キーの無いコマンドなら足す） |
| `a` | 割り当てを足す |
| `d` / `x` | その割り当てを外す |
| `s` | その割り当ての範囲を次のものに変える |
| `r` | そのコマンドを既定の割り当てに戻す |
| `/` | 名前・ID・キーで絞り込む（`Enter` で決める、`Esc` で消す） |
| `Esc` / `q` | 設定画面を閉じる |

- 押し直すときは、割り当てたいキーをそのまま押す。最後のキーから 1 秒で決まるので、
  `<Space>ff` のような続けて押すキーも押せる。最初に `Esc` を押すとやめる（`Esc` そのものは
  ここでは割り当てられないので、ファイルに書く）。記録している間は、どのコマンドもキーで
  走らない。
- 範囲は、`⌘` の組み合わせなら `global`、それ以外は元の割り当て（無ければ `normal`）に
  そろえる。違えば `s` で変える。
- 同じ範囲で同じキーを持つコマンドがあれば、その行の下に出す。
- 変えるとすぐに効き、既定と違うものだけを `keybindings.json` に書く。既定に戻した
  コマンドはファイルから消える。ファイルに手で書いた、アプリに無いコマンドの ID は残す。

### ファイルに書く

パレットの「キーの割り当てを変える」（`app.editKeybindings`）か、設定画面の「一般」の
「キーの割り当てのファイル」で、無ければ空の形で作り、既定のテキストエディタで開く。

```json
{
  "app.focusSidebar": [
    { "scope": "normal", "sequence": "<C-h>" },
    { "scope": "global", "sequence": "⌘0" }
  ],
  "app.focusEditor": [{ "scope": "sidebar", "sequence": "<C-l>" }],
  "vault.trash": []
}
```

- 鍵はコマンドの ID。ID は設定画面の「キー」と、キー操作の一覧（`⌘/`）に出る。
- 値はそのコマンドの割り当ての**すべて**。書いたものが既定を丸ごと置き換える（足したい
  ときは既定のものも書く）。空の配列はキーを外す。
- `scope` は「コマンドとキーの範囲」の表のどれか。`sequence` はこの文書の表記で書く。
- DIAGRAM モードを TREE モードと呼んでいたころの ID（`tree.addChild` など）と範囲（`tree`）は、
  読むときに `diagram.addChild`・`diagram` へ読み替える。
- 保存してアプリのウィンドウに戻ると読み直す。パレットの「キーの割り当てを読み直す」でも
  読み直せる。
- 書き間違い（JSON として読めない、無い範囲、無いコマンドの ID）はステータスバーに出す。
  読めなかったときは、それまでの割り当てのまま動く。
- 変えた割り当ては、パレット・which-key・キー一覧・サイドバーの案内・空の画面の案内に
  そのまま出る。DIAGRAM モードの次のキーの案内（`KeyGuide`）はまだ既定のキーを書いたまま。
- Vim 側で割り当ててあるキー（`za`、`:w` など、一覧に出るだけのもの）は、置き換えても
  Vim の中では効き続ける。INSERT のノード編集の `Enter` / `Tab` も変えられない。

## 設定画面

`⌘,` か、サイドバー右上の歯車で開く。`Tab`（`Shift+Tab` で逆向き）で「一般」「テーマ」
「キー」を切り替え、`Esc` / `q` で閉じる。「キー」は上の「割り当てを変える」にある。
「一般」は `j` / `k` で項目を移り、`h` / `l`（`Enter` / `Space`）で値を変える。セレクタの項目
（文字の大きさ、BGM、BGM の音量）は `Enter` / `Space` で一覧を開き、`j` / `k` で選んで `Enter` で決める
（`Esc` でやめる）。`h` / `l` なら一覧を開かずに 1 段ずつ変わる。

| 項目 | 値 |
| --- | --- |
| サイドバーの位置 | 左 / 右 |
| 文字の大きさ | セレクタで 12 / 13 / 14（既定）/ 15 / 16 / 17 / 18 / 20px。本文の大きさで、ほかの文字も比例して変わる |
| BGM | セレクタで 流さない（既定）/ テーマに合わせる / 山の風 / 渓流 / 波 / 森の鳥 / 夏の夜の虫 / 焚き火 / 雨。流している音はステータスバーの右に「♪ 名前」で出す |
| BGM の音量 | セレクタで 10〜100%（10% 刻み、既定 50%） |
| DIAGRAM モードの次のキーの案内 | 出す / 出さない。出さないときは案内の行もノードを足す印も出さない |
| 保管庫 | `Enter` で選び直す |
| キーの割り当てのファイル | `Enter` で `keybindings.json` を開く |

値は変えるとすぐに効き、アプリの状態として保存する。

「テーマ」は、上にプリセットを 6 列のグリッドで並べ、その下に書体のセレクタ、さらに下に色のトークンを 1 行ずつ並べる
（[Kotoba](kotoba-design-system.md) の「テーマ」）。トークンは意味のもの（背景・文字・
プライマリ・境界・選択など）を先に、それらが指すパレットの段を最後に置く。

| キー | 動作 |
| --- | --- |
| `h` / `j` / `k` / `l` | グリッドの升を移る。グリッドの最後の行で `j` を押すとトークンの一覧へ |
| `j` / `k`、`g` / `G` | 書体とトークンの行を移る / 最初・最後へ |
| `Enter` / `Space`（書体） | 書体の一覧を開く。`j` / `k` で選んで `Enter` で決める。一覧では書体ごとにその書体で名前を出す |
| `Enter` / `Space`（グリッド） | そのプリセットに切り替える。最後の升は、今のテーマを写したカスタムを作る |
| `e`（カスタムの升） | 名前を変える |
| `d` / `x`（カスタムの升） | 消す（続けて `y` で消す。ほかのキーでやめる） |
| `Enter` / `c`（トークン） | 値を選ぶ。意味のトークンはパレットの段から `h` / `l` で選び、`#` で色を直に書く。パレットの段は色を直に書く |
| `r`（トークン） | 元にした組み込みのプリセットの値に戻す |

- 組み込みのプリセットは変えられない。そこで色を変えると、写したカスタム（「カスタム」
  「カスタム 2」…）ができて、そちらを選んだ状態になる。カスタムは変えるとすぐに保存される。
- 行の左の色見本を押すと、macOS の色パネルで選べる。
- 書体はプリセットに属さず、どのテーマでも同じものを使う（[Kotoba](kotoba-design-system.md) の「typography」）。
- カスタムを消すと、選んでいたなら元にした組み込みのプリセットへ戻る。

## 手がかり（シグニファイア）

キーボードで使う道具は、押せるキーが目に見えないと覚えられない。次の手がかりを常に
出し、マウスで操作した人も次からキーを使えるようにする。

| 手がかり | 出す場所 | 中身 |
| --- | --- | --- |
| モード表示 | ステータスバー | 今のモード。DIAGRAM では操作中のブロックの枠も変える |
| which-key | 画面の下 | `<Space>` のあとに押せるキーと、その動作 |
| ヒント | 押せる要素の上 | 1〜2 文字のラベル。打つとそこへ移る |
| 次のキーの案内 | 選んでいるブロックの下端、全画面では上端 | `o 兄弟` `Tab 子` `i 編集` のように主なものだけ。ノード編集中は Enter / Tab の意味。いちばん小さい文字（`text-2xs`）で控えめに出し、キーは `Code` の見た目にする。パレットの「次のキーの案内を切り替える」で消せ、消すと何も出さない（倍率のボタンだけが残る） |
| ノードを足す印 | DIAGRAM モードで選んでいるノードの右（子が無いときだけ）と下（ノードの幅の中央） | 破線の枠の `+Tab` / `+o`。DIAGRAM (INSERT) では下が `+Enter` になり、右の `+Tab` とともに中身に文字があるときだけ出す（空のまま `Enter` を押すとノードが消え、`Tab` は何もしないため）。DIAGRAM (NORMAL) では押しても足せる（INSERT では押せない。確定はノードのエディタが持つため）。ノードの間の空きに重ねるので、出し入れしてもツリーは動かない。次のキーの案内と一緒に消える |
| コマンドパレット | `⌘K` | すべてのコマンドと割り当てキー。打った名前で絞り込む |
| ツールチップ | マウスで押せる要素 | その操作の割り当てキー（ボタン、チェックボックス、折りたたみの数） |
| フォーカスリング | フォーカスのある領域 | サイドバー・エディタ・パレットのどこにキー入力が行くか |
